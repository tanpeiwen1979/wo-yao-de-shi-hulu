# 我要的是葫芦

小学语文二年级上册 · 第五单元 · 第13课 教学资源包

## 课文简介

《我要的是葫芦》是一篇寓言故事，讲述从前有个人种了一棵葫芦，叶子上长了蚜虫却不治，只盯着葫芦，结果小葫芦一个个变黄掉落的故事。课文告诉我们：事物之间是有联系的，要重视细节，不能只看结果。

## 课文原文

> 从前，有个人种了一棵葫芦。
>
> 细长的葫芦藤上长满了绿叶，开出了雪白的小花。
>
> 花谢以后，藤上挂了几个小葫芦。
>
> 多么可爱的小葫芦啊！那个人每天都要去看几次。
>
> 有一天，他看见叶子上爬着一些蚜虫，心里想，有几个蚜虫怕什么！
>
> 他盯着小葫芦自言自语地说：
>
> "我的小葫芦，快长啊，快长啊！长得赛过大南瓜才好呢！"
>
> 一个邻居看见了，对他说：
>
> "你别光盯着葫芦了，叶子上生了蚜虫，快治一治吧！"
>
> 那个人感到很奇怪，说：
>
> "什么？叶子上的虫还用治？我要的是葫芦。"
>
> 没过几天，叶子上的蚜虫更多了。
>
> 小葫芦慢慢地变黄了，一个一个都落了。
